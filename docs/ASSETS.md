# Asset and audio notes — Batch 2

This batch intentionally uses generated placeholders only:
- Vehicles: Phaser vector rectangles with text labels and configured vehicle colours.
- Obstacles: Unicode emoji glyphs (thela, bhains, barrier) rendered by the system font.
- Passenger stream: coloured Phaser circles generated from each level's passenger colour list.
- Sound: short Web Audio oscillator tones generated at runtime for blocked taps and successful exits.
- Haptics: browser vibration API fallback when the runtime exposes it.

No third-party image, music, or sound files are bundled in this batch, so there are no external asset licences to attribute. These placeholders are not final production art/audio. Device vibration and browser audio support vary by platform and must be verified on Android hardware.
